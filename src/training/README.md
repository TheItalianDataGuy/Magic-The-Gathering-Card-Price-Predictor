# Training (planned)

This folder is reserved for future work related to model training and evaluation.

Planned components may include:
- walk-forward backtesting utilities
- comparison of baseline models vs ARIMA / other time-series models
- storage of trained model artefacts and parameters
- performance metrics and evaluation reports

The current version of the project focuses on a robust, end-to-end
data ingestion, forecasting, and monitoring pipeline using baseline methods.
